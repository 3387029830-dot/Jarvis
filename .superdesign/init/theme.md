# Theme

## Runtime source

`apps/desktop/src/renderer/src/design-system/tokens.css`

## Direction

- Root `#07090d`, elevated `#0c1017`, soft `#111722`, and an 82% overlay.
- Primary `#f1f4f8`, secondary `#a5afbd`, muted `#717d8f`, and inverse graphite text.
- Ice blue `#8fb7ff` is the only primary accent.
- Green, amber, and red are reserved for success, warning, and danger.
- Windows Chinese system fonts lead the UI stack; a system serif stack is an editorial accent.
- Chinese reading line height is `1.85`; readable widths are `46ch` and `68ch`.
- Spacing uses a 4px base rhythm from 4px through 96px.
- Radius ranges from 4px through 18px, with full pills reserved for compact status.
- Motion durations are 80ms, 140ms, 220ms, and 360ms with standard/emphasized curves.
- Reduced motion collapses durations, removes translation/scale/spinning/continuous animation, and
  retains static color and border state.

The showcase avoids gradients, persistent glowing borders, glass-heavy surfaces, metrics, dense
grids, and product-screen content.
