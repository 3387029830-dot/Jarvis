# ADR-0001: Center the product on personal cognition

## Status

Accepted

## Decision

Jarvis will be designed as a voice-first personal cognition companion rather than a programming assistant, productivity dashboard, or generic automation agent.

## Consequences

- Voice, continuity, cross-domain exploration, cognition mapping, and belief evolution receive priority.
- GitHub and programming capabilities are not part of the foundation scope.
- Obsidian is an export adapter.
- Product success is measured by daily-use experience and meaningful cognition continuity, not tool count.
