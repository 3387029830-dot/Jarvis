# ADR-0005：简体中文作为正式产品默认语言

- 状态：已接受
- 日期：2026-07-30

## 背景

Jarvis 的当前产品所有者和首要验收环境使用简体中文。JAR-002 已证明中文字体、行高和中英文混排需要被当作基础设计约束，而不是在英文界面完成后再做翻译。JAR-003 开始形成正式产品导航、状态、空状态和隐私说明，因此需要确定长期语言边界。

## 决定

简体中文是 Jarvis 正式产品体验的默认语言。

- 导航、操作、状态、错误、空状态、隐私、可访问性和帮助文案使用简体中文。
- 英文只用于 Jarvis 品牌、代码/API 标识、必要专有名词和弱化的辅助技术标签。
- 正式静态产品文案集中在强类型 `zh-CN` 目录。
- 动态内容通过强类型 view-model 进入组件。
- 日期和数字通过 `Intl` 的 `zh-CN` locale 格式化。
- 开发 showcase 可以保留组件和 token 名称，但解释内容应中文优先。

## 原因

- 让真实目标用户无需依赖英文理解主要操作和风险边界。
- 在组件与页面形成时直接验证中文排版，避免后期翻译导致布局返工。
- 通过集中、强类型文案目录减少散落文案和能力表述不一致。
- 明确 Mock、未录音和未保存状态，避免视觉完成度掩盖功能边界。

## 后果

- 新的正式产品页面必须先提供完整简体中文文案。
- 未来增加其他 locale 时，可以扩展同一类型目录，但不能维护互相独立的产品语义。
- 中文文案变更需要同时检查行宽、行高、键盘状态和截图证据。
- 代码标识和开发命令不需要翻译。
